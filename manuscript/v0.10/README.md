# nutau-prop manuscript v0.10

This version corrects the scientific scope and records the canonical v0.7/v0.8 checkpoint from the ChatGPT research thread.

Central subject: momentum-enhanced tau-neutrino propagation through the Earth.  The cosmogenic/UHE IceCube-KM3NeT comparison is treated as the observational constraint that creates the current tension; it is not the goal of the separate UHECR proton-fraction project and this manuscript is not framed as a KM3-230213A explanation paper.

The v0.8 crude 2.3026-event common-flux screen is retained only as historical screening.  The subsequent v0.9 energy-dependent public-data diagnostic remains a later refinement in the repository and is not erased by this checkpoint.
